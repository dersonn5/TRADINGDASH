# 📊 MOC — Pós-Trade e Aprendizado

> **Camada 4 — O Ciclo de Evolução**
> O trading bem-sucedido é o resultado do feedback contínuo.
> O que fazemos após o fechamento do trade define a velocidade de crescimento do nosso cérebro de trading.

---

## Estrutura do Módulo Pós-Trade

| Nota | Propósito | Foco |
|---|---|---|
| [[Protocolo_de_Review\|🔍 Protocolo de Review]] | Passo a passo para dissecar o trade | Processo Técnico |
| [[Licoes_e_Ajustes\|💡 Lições e Ajustes]] | Notas vivas de refinamento do modelo | Otimização de Edge |
| [[Gravacao_Sinapse_Obsidian\|🧬 Gravação Sináptica]] | Template e diretrizes de logs no diário | Integração de Dados |
| [[Cenarios_Finalizacao\|🏁 Cenários de Finalização]] | Análise estatística de como o trade acabou | Métricas e Nuances |

---

## O Fluxo de Feedback Sináptico

```
[Trade Fechado]
      │
      ▼
1. Executar [[Protocolo_de_Review]]
      │
      ▼
2. Copiar template de [[Gravacao_Sinapse_Obsidian]] para o Diário Mensal
      │
      ▼
3. Classificar o desfecho em [[Cenarios_Finalizacao]]
      │
      ▼
4. Se houver erro ou desvio, atualizar [[Licoes_e_Ajustes]]
      │
      ▼
5. Rodar [[../../scratch/obsidian_brain_linker|Obsidian Brain Linker]] para conectar as novas notas
```
